Как сервис обрабатывает данные, документы и результаты.

2. Какие данные используются

Сервис может обрабатывать электронную почту, технические данные, сведения об оплате, параметры выбранной услуги, введённые пользователем описания ситуаций, тексты документов, загруженные файлы и сформированные результаты.

3. Как обрабатываются документы

Способ обработки зависит от выбранного продукта и формата материала. Для PDF с текстовым слоем, DOCX и TXT текст может извлекаться непосредственно в браузере пользователя, после чего на сервер передаётся извлечённый текст.

Фотографии и сканы документов, страницы PDF без текстового слоя, а также старые файлы DOC могут кратковременно передаваться серверному компоненту и, когда это необходимо для распознавания, поставщику модели искусственного интеллекта. Это нужно только для извлечения текста перед последующим анализом. В сервисах проверки и объяснения документа исходные фото, сканы и DOC не сохраняются как часть результата.

Для полного разбора ситуации загруженные пользователем документы передаются в приватное серверное хранилище, чтобы сервис мог сопоставить несколько материалов между собой и сформировать единый анализ. Доступ к таким файлам ограничен авторизованным пользователем и серверными компонентами сервиса.

Поддерживаются только форматы и размеры файлов, указанные в интерфейсе конкретного продукта.

4. Для чего нужны данные

Данные используются для выполнения выбранной услуги, формирования результата, подтверждения оплаты, предоставления доступа к оплаченному результату, технической поддержки, предотвращения злоупотреблений и обеспечения работы сервиса.

5. Сторонние сервисы

Для работы сервиса могут использоваться внешние поставщики инфраструктуры, облачного хранения, обработки текста и изображений, моделей искусственного интеллекта, авторизации, хостинга и платежей. Им передаются только данные, необходимые для выполнения соответствующей функции. Содержимое документов и изображений может передаваться поставщику модели искусственного интеллекта для распознавания или формирования анализа.

6. Электронная почта и авторизация

Электронная почта используется для привязки оплаты и отправки одноразовой ссылки для доступа к результату. Пароль от пользователя не требуется.

7. Срок хранения

Данные и загруженные материалы хранятся столько, сколько необходимо для формирования и предоставления результата, повторного доступа к нему, подтверждения оплаты, исполнения обязательных требований и защиты законных интересов. Технические сроки хранения могут отличаться для разных типов данных. Пользователь может обратиться с запросом по поводу удаления переданных материалов, если их дальнейшее хранение не требуется по закону или для исполнения обязательств.

8. Ответственность пользователя

Передавая документы и иные материалы, пользователь подтверждает, что вправе передавать их для обработки и самостоятельно определяет объём содержащихся в них персональных, коммерческих и иных сведений.
