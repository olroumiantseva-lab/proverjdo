Как сервис обрабатывает данные и текст договора.

1. Кто обрабатывает данные

ИП Румянцев Сергей Сергеевич, ИНН 402807838797, ОГРНИП 325400000062800.

2. Какие данные используются

Сервис может обрабатывать электронную почту, технические данные, сведения об оплате, параметры проверки и текст, извлечённый из загруженного договора.

3. Как обрабатывается файл

PDF, DOCX или TXT разбирается в браузере пользователя. Исходный файл не отправляется на сервер сервисом «Проверь до». После запуска проверки на сервер передаётся извлечённый текст и выбранные пользователем параметры проверки.

4. Для чего нужны данные

Данные используются для выполнения проверки, формирования результата, подтверждения оплаты, предоставления доступа к оплаченному разбору, технической поддержки и обеспечения работы сервиса.

5. Сторонние сервисы

Для работы сервиса могут использоваться внешние поставщики инфраструктуры, обработки текста, авторизации, хостинга и платежей. Им передаются только данные, необходимые для выполнения соответствующей функции. Текст договора может передаваться поставщику модели искусственного интеллекта для формирования анализа.

6. Электронная почта и авторизация

Электронная почта используется для привязки оплаты и отправки одноразовой ссылки для доступа к результату. Пароль от пользователя не требуется.

7. Срок хранения

Данные хранятся столько, сколько необходимо для предоставления результата, подтверждения оплаты, исполнения обязательных требований и защиты законных интересов. Технические сроки хранения могут отличаться для разных типов данных.
