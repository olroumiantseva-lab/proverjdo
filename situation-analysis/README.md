# Situation analysis intake

Первый экран апсейл-продукта полного разбора ситуации.

Сейчас реализованы:
- переход с готового письма;
- автоподстановка ситуации и цели из текущего письма;
- дополнительное описание обстоятельств;
- выбор нескольких документов;
- локальное сохранение intake в sessionStorage.

Оплата, загрузка файлов на backend и сам анализ пока не подключены.
